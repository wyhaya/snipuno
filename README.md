# Snipuno

Snipuno is a simple, lightweight, open-source screen capture and annotation software.

![Snipuno](https://github.com/user-attachments/assets/eb8de1d8-147c-428d-869e-74d7cc982307)

## Features

- Full-screen screenshot
- Area screenshot
- Color picker
- Floating window
- Tools:
  - Select
  - Rectangle
  - Ellipse
  - Arrow
  - Line (solid, dashed, wavy)
  - Brush
  - Text
  - Number
  - Redact (blur or mosaic)
  - Spotlight
  - Magnifier
  - Measure & guides
  - Crop
  - Add image
